الجزء 1 — الرؤية والملخص التنفيذي

1.1 ما هي ملامح؟

ملامح.ps أول منصة فلسطينية متخصصة تجمع:

  • دليل أطباء (أسنان، عيون، جلدية، تجميل، أنف وأذن)
  • حجز إلكتروني + إشعارات
  • عروض وبطاقة خصم
  • باقات اشتراك للأطباء (دليل · مميز · إعلانات)
  • موقع + تطبيق موبايل متزامنان

شعار التموضع: «ملامح — دليلك لصحة وجمال الوجه في فلسطين»

1.2 North Star Metric (المؤشر الرئيسي)

عدد الحجوزات المكتملة شهرياً — لأنه يربط: أطباء (عرض) + مرضى (طلب) + قيمة المنصة.

مرحلة North Star أطباء MAU إيراد شهري
إطلاق (M1–3) 200 حجز/شهر 100 3K $500
نمو (M4–12) 2,000 حجز/شهر 500 25K $5K
نضج (M13–24) 8,000 حجز/شهر 1,200 80K $15K
قيادة (M25–36) 20,000 حجز/شهر 2,500 200K $40K

1.3 المبادئ غير القابلة للتفاوض

  1. الثقة أولاً — لا طبيب غير موثّق على المنصة
  2. بساطة الحجز — أقل من 60 ثانية من البحث للتأكيد
  3. تزامن الموقع والتطبيق — نفس المحتوى دائماً
  4. B2B يغذّي B2C — بدون أطباء لا مرضى
  5. البيانات تقود القرار — كل أسبوع: أرقام، لا انطباعات

الجزء 7 — إدارة المشروع البرمجي

7.1 Methodology: Scrumban (Solo → Small Team)

  • Backlog في GitHub Issues أو Linear
  • Sprint أسبوعان
  • WIP limit: 3 tasks max in progress
  • Release: كل جمعة (hotfix anytime)

7.2 Definition of Done

  • Code merged to main
  • Typecheck pass
  • Tested on web + mobile
  • Deployed production
  • Documented if API change

7.3 Release Checklist

  • npm run supabase:db:push if migrations
  • Vercel deploy green
  • EAS build if native change
  • Smoke test: booking, ticker, notifications
  • Announce in admin ticker if user-facing

7.4 Tech Debt Budget

20% of each sprint = refactoring, security, performance — لا تتنازل عنها.
