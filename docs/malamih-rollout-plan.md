# خطة تنفيذ ملامح — التحديث الشامل

## ✅ مكتمل

### التطبيق (موبايل)
- إعادة هيكلة كاملة: 5 تبويبات (الرئيسية · الأطباء · حجز · عروض · المزيد)
- تبويب "المزيد" منظم: أقسام واضحة + إجراءات سريعة + إشعارات + دخول طبيب/أدمن
- إصلاح تعطل صفحة الطبيب
- شريط إخباري ديناميكي تحت الناف بار
- إشعارات صوتية + اهتزاز للطبيب والأدمن (polling كل 12 ثانية)
- تسجيل Push حسب الدور (مريض / طبيب / أدمن)
- صفحة إشعارات الأدمن داخل التطبيق
- صفحة الباقات `/subscriptions` (عرض أسعار فقط — بدون دفع)

### الموقع (ويب)
- حذف مقارنة الأطباء
- شريط إخباري ديناميكي
- صفحة الباقات + طلب اشتراك يدوي
- لوحة أدمن: الشريط الإخباري + الاشتراكات + الإشعارات
- إشعارات عربية + صوت على لوحة الأدمن

### قاعدة البيانات
- `subscription_packages` + `doctor_subscriptions` + `news_ticker_items`
- `doctors.active_package_slug` + `package_expires_at`
- `advertisements.display_priority` لترتيب الإعلانات

### الباقات (عرض فقط)
| الباقة | السعر | المدة |
|--------|-------|-------|
| الدليل | $100 | سنوي (بدل $120) |
| المميز | $300 | سنوي |
| العروض والإعلانات | $50 | شهري/إعلان |

## 🔄 التفعيل اليدوي (بدون دفع إلكتروني)
1. العميل يطلب من `/subscriptions`
2. الأدمن يفعّل من `/admin/subscriptions`
3. النظام يحدّث باقة الطبيب وترتيب إعلاناته تلقائياً

## أوامر التشغيل
```bash
npm run supabase:db:push
npm run dev:web
npm run build:apk
npm run build:android:store   # Google Play
npm run build:ios:store       # App Store
```

راجع `docs/store-publish.md` لخطوات النشر الكاملة.
