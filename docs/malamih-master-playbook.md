# الجزء 1 — الرؤية والملخص التنفيذي

## 1.1 ما هي ملامح؟

**ملامح.ps** أول منصة فلسطينية متخصصة تجمع:
- دليل أطباء (أسنان، عيون، جلدية، تجميل، أنف وأذن)
- حجز إلكتروني + إشعارات
- عروض وبطاقة خصم
- باقات اشتراك للأطباء (دليل · مميز · إعلانات)
- موقع + تطبيق موبايل متزامنان

**شعار التموضع:** *«ملامح — دليلك لصحة وجمال الوجه في فلسطين»*

## 1.2 North Star Metric (المؤشر الرئيسي)

**عدد الحجوزات المكتملة شهرياً** — لأنه يربط: أطباء (عرض) + مرضى (طلب) + قيمة المنصة.

| مرحلة | North Star | أطباء | MAU | إيراد شهري |
|-------|------------|-------|-----|------------|
| إطلاق (M1–3) | 200 حجز/شهر | 100 | 3K | $500 |
| نمو (M4–12) | 2,000 حجز/شهر | 500 | 25K | $5K |
| نضج (M13–24) | 8,000 حجز/شهر | 1,200 | 80K | $15K |
| قيادة (M25–36) | 20,000 حجز/شهر | 2,500 | 200K | $40K |

## 1.3 المبادئ غير القابلة للتفاوض

1. **الثقة أولاً** — لا طبيب غير موثّق على المنصة
2. **بساطة الحجز** — أقل من 60 ثانية من البحث للتأكيد
3. **تزامن الموقع والتطبيق** — نفس المحتوى دائماً
4. **B2B يغذّي B2C** — بدون أطباء لا مرضى
5. **البيانات تقود القرار** — كل أسبوع: أرقام، لا انطباعات

# الجزء 3 — دورك كمؤسس مبرمج (Product Owner)

## 3.1 تقسيم وقتك — المراحل

### المرحلة A: بناء المنتج (M0–M3) — 80% Dev · 20% Business

| اليوم | Block 1 (صباح) | Block 2 (ظهر) | Block 3 (مساء) |
|-------|----------------|---------------|----------------|
| إث | تطوير features | مبيعات (5 عيادات) | محتوى/سوشال |
| ث | تطوير + bugs | SEO + analytics | متابعة حجوزات |
| أر | code review + deploy | مكالمات أطباء | تخطيط أسبوع |
| خ | تطوير | زيارة ميدانية | — |
| ج | testing + release | admin + support | KPI review |

### المرحلة B: نمو (M4–M12) — 40% Dev · 40% Business · 20% Leadership

- **Dev:** architecture، features كبرى، code review فقط
- **Business:** استراتيجية، شراكات، توظيف، pricing
- **Leadership:** 1:1 مع المندوبين، culture، vision

### المرحلة C: قيادة (M12+) — 10% Dev · 50% Business · 40% Leadership

- Dev → CTO أو lead developer
- أنت → PO + CEO

## 3.2 Sprint Calendar (Product Owner)

| الجمعة W1 | Demo داخلي + deploy staging |
| الاثنين W2 | Mid-sprint check |

# الجزء 5 — مندوبو المبيعات — الدليل الكامل

## 5.1 الهدف الوظيفي (Job Description)

**العنوان:** مندوب مبيعات ميداني — قطاع طبي/تجميل  
**التقارير إلى:** Product Owner (لاحقاً Sales Manager)  
**الموقع:** رام الله + [مدينة حسب التوزيع]

**المسؤوليات:**
- زيارة 8–12 عيادة/أسبوع
- تسجيل 4–6 أطباء جدد/شهر
- upsell باقات (دليل → مميز)
- جمع feedback من الميدان
- تمثيل ملامح باحترافية

## 5.2 الهيكل التعويضي (Compensation)

| المكون | المبلغ | ملاحظة |
|--------|--------|--------|
| راتب أساس | $400–600/شهر | حسب الخبرة |

| عمولة باقة دليل | $20 | عند الدفع |
| عمولة باقة مميز | $50 | عند الدفع |
| عمولة إعلان | $10/إعلان | — |
| **Bonus شهري** | $100 | إذا ≥6 تسجيلات + 2 باقات |

**مثال دخل مندوب جيد:** $500 + $90 (6×15) + $100 (2×50) + $100 bonus = **$790/شهر**


# الجزء 7 — إدارة المشروع البرمجي

## 7.1 Methodology: Scrumban (Solo → Small Team)

- **Backlog** في GitHub Issues أو Linear
- **Sprint** أسبوعان
- **WIP limit:** 3 tasks max in progress
- **Release:** كل جمعة (hotfix anytime)

## 7.2 Definition of Done

- [ ] Code merged to main
- [ ] Typecheck pass
- [ ] Tested on web + mobile
- [ ] Deployed production
- [ ] Documented if API change

## 7.3 Release Checklist

- [ ] `npm run supabase:db:push` if migrations
- [ ] Vercel deploy green
- [ ] EAS build if native change
- [ ] Smoke test: booking, ticker, notifications
- [ ] Announce in admin ticker if user-facing

## 7.4 Tech Debt Budget

**20% of each sprint** = refactoring, security, performance — لا تتنازل عنها.
