## الملخص التنفيذي

**ملامح** منصة رقمية تجمع بين دليل الأطباء، الحجز، العروض، بطاقة الخصم، والإعلانات — في سوق فلسطيني لم يُخدَم بهذا الشكل من قبل. الفرصة: **أول محرك بحث موثوق** لطب الأسنان، العيون، الجلدية، التجميل، والأنف والأذن والحنجرة.

**الهدف خلال 12 شهراً:**
- 500+ طبيب/عيادة مسجّلين
- 50,000+ زيارة شهرية للموقع والتطبيق
- 2,000+ حجز شهري
- أن تصبح «ملامح» الكلمة الأولى عند البحث عن طبيب في فلسطين

## 1. تحليل السوق والفرصة

### 1.1 المشكلة
| المشكلة | الأثر |
|---------|-------|
| لا يوجد دليل موحّد للتخصصات الدقيقة | المريض يبحث على فيسبوك وواتساب و«سمعة» |
| الحجز عبر مكالمات | ضياع وقت، no-show، فوضى |
| الأطباء لا يملكون حضوراً رقمياً | خسارة مراجعين لصالح من يظهر أولاً |
| الإعلانات الطبية عشوائية | صعوبة الوصول للجمهور المناسب |

### 1.2 الحل — ملامح
- **للمريض:** بحث، مقارنة، حجز، عروض، بطاقة خصم
- **للطبيب:** ملف احترافي، ظهور، حجوزات، إشعارات، باقات اشتراك
- **للإدارة:** لوحة تحكم، إعلانات، شريط إخباري، تحليلات

### 1.3 المنافسون والتميّز
| البديل | نقطة ضعفه | تميّز ملامح |
|--------|-----------|-------------|
| فيسبوك/إنستغرام | غير منظم، لا حجز | دليل + حجز + توثيق |
| Google Maps | عام، بدون تخصص طبي | تخصصات دقيقة + عروض |
| واتساب جماعات | فوضى | منصة واحدة موثوقة |
| إعلانات تقليدية | مكلفة وغير مستهدفة | استهداف حسب مدينة وتخصص |

**شعار التموضع:** *«ملامح — دليلك لصحة وجمال الوجه في فلسطين»*

## 4. خطة التسويق التفصيلية

### 4.1 التسويق الرقمي (Digital)

#### أ) SEO — محركات البحث (أولوية عالية — مجاني)
```
صفحات مستهدفة:
• /doctors/search?city=رام+الله&specialty=أسنان
• «أفضل طبيب [تخصص] في [مدينة]» — 50 صفحة
• مدونة: نصائح صحة، before/after، أسئلة شائعة
```
**كلمات مفتاحية:**
- طبيب أسنان فلسطin / رام الله / نابlus / الخليل
- عيادة تجميل / فيلر / بوتox / تبييض أسنان
- حجز موعد طبيب / دليل أطباء فلسطين
- عروض أسنان / خصم عيادة

#### ب) Meta Ads (فيسبوك + إنستغرام)
| الحملة | الجمهور | الميزانية الشهرية المقترحة |
|--------|---------|---------------------------|
| تحميل التطبيق | 18–45، فلسطين | $150–300 |
| انضم كطبيب | أطباء، أصحاب عيادات | $100–200 |
| عروض وخصومات | مهتمون بتجميل/أسنان | $100–200 |

**Creative:** فيديو 15 ثانية — «احجز طبيبك في 60 ثانية» + شهادات حقيقية

#### ج) Google Ads
- Search: «طبيب أسنان قريب مني»، «حجز عيادة»
- Display: retargeting لزوار malamih.ps

#### د) TikTok / Reels
| نوع المحتوى | مثال |
|-------------|------|
| تعليمي | «5 أخطاء بعد تبييض الأسنان» |

**هدف:** 1 فيديو viral كل شهر = 100K+ مشاهدة

## 5. استراتيجية الوصول للزبائن (Customer Acquisition)

### 5.1 قمع التحويل (Funnel)

```
وعي → اهتمام → قرار → حجز → ولاء
 │      │        │       │      │
 │      │        │       │      └─ بطاقة خصم + إشعارات عروض
 │      │        │       └─ حجز سهل + تأكيد فوري
 │      │        └─ مقارنة أطباء + تقييمات + عروض
 │      └─ محتوى تعليمي + SEO + إعلانات
 └─ PR + social + word of mouth
```

### 5.2 CAC — تكلفة اكتساب زبون (تقدير)

| القناة | CAC تقريبي | LTV (قيمة العميل) |
|--------|------------|-------------------|
| SEO (عضوي) | $0–2 | عالي — زائر متكرر |
| Meta Ads | $3–8 | متوسط |
| Influencer | $5–15 | متوسط–عالي |
| ميداني/QR | $1–3 | عالي — intent قوي |
| Referral | $0–1 | الأعلى |

### 5.3 برنامج الإحالة (Referral)

**للمريض:**
- «ادعُ صديق → خصم 10% على أول حجز» (عبر بطاقة الخصم)

**للطبيب:**
- «ادعُ طبيب → شهر مجاني باقة مميز»
- كود إحالة فريد لكل طبيب

### 5.4 Retention — الاحتفاظ

| التكتيك | التنفيذ |
|---------|---------|
| Push notifications | عروض جديدة، تذكير موعد |
| شريط إعلانات | `/admin/ticker` — عروض موسمية |
| Email/WhatsApp | «موعدك غداً»، «عروض الأسبوع» |
| Gamification | نقاط بطاقة الخصم |
